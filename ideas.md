## Lessons

Raw capture point for operator/agent lessons + gotchas. `/noldor-absorb` classifies each unfiled bullet (`drop | gotcha | actionable | feedback`), files it into framework docs, and stamps `[absorbed YYYY-MM-DD → <dest>]`. Stamped bullets may be pruned — git history is the audit trail.

- Commit trailers only count in the message's LAST paragraph: a `Noldor-Phase-Revert: 1` in its own block above `Co-Authored-By` is ignored, and `validate-trailer` then demands a spec that does not exist yet. Keep every `Noldor-*` line in the final block. (PR #681, 2026-10-07)
- On an attach session, a `slug` key left in `.noldor/session.json` (from the `-new` path the gate started on) makes `validate-trailer` look for an FD by that slug and refuse the commit. Attach markers carry `parent` + `enhancement` only. (PR #681, 2026-10-07)
- `pnpm noldor ... --confirm-section 'The check: \`noldor dead-code\`'` lost everything after the colon: pnpm re-runs the script through a shell, so backticks inside an argument become command substitution even when the outer shell quoted them. Use the heading-prefix form (`--confirm-section 'The check'`) for any heading with backticks. (dead-code-detection-with-knip, PR #679, 2026-10-07)
- Adding a devDependency from a feature worktree trips `checks shared-files` (package.json + pnpm-lock.yaml are blocked from `.worktrees/`). When the dependency IS the feature, commit with `NOLDOR_ALLOW_SHARED=1` — the documented override — rather than moving the edit to main. Worth a line in the spec template's "Files touched" guidance so it is expected, not discovered at commit. (PR #679, 2026-10-07)
- knip skips unused exports in entry files by default, and in noldor every CLI leaf is an entry, so the default leaves ~170 files unchecked; `includeEntryExports: true` raised the found set from 275 to 389. (PR #679, 2026-10-07)
- The first `// @fd: <slug>` header on an FD flips `sync code-links` (and the pre-commit `code-links-auto-high` hook) into tag-built mode for that FD: links.code is rebuilt from headers alone and every hand-listed file is dropped. Adding one header to cr-re-round-cap / ui-design-review-lane / pnpm-release-resume took the orphan count from 5 to 33. For an FD with no headers yet, add the file to its links.code by hand instead (fd-headers-for-five-real-gap-orphans, PR #677, 2026-10-07). Worth a warning in the sync output, or a `--dry-run` diff in the triage advice that says "add a header".
- In this repo `pnpm noldor` is a package script, so pnpm hands its args to `sh` inside double quotes: backticks or `$(...)` in a `triage retro` note run as shell commands (a note quoting `git merge --ff-only --autostash` ran it). Here call `node bin/noldor.mjs triage retro`; consumers that call the installed bin are not affected (probed in charuy). (session-retro-auto-capture, PR #687, 2026-10-08)
- An attach session marker that also carries `slug` makes commit-msg refuse with "FD does not exist: <slug>"; the attach marker holds only `parent` + `enhancement`. (session-retro-auto-capture, PR #687, 2026-10-08)
- `git merge --ff-only --autostash` exits 0 when re-applying the stash conflicts and leaves UU files; check `git diff --name-only --diff-filter=U` after it (`ffSyncMain` does). (session-retro-auto-capture, PR #687, 2026-10-08)
- A rebase onto main can turn `gate-skill-layout` red on the specs-only-new load budget: two sessions adding gate prose only collide after the rebase, at the PR-conflict stage. (session-retro-auto-capture, PR #687, 2026-10-08)
- A probe for argv re-parsing must print by itself: `pnpm noldor --help '$(printf INJ%sPROBE ECTED >&2)'` shows INJECTEDPROBE only when pnpm's `sh` expanded it. A payload that only becomes an argument never surfaces under `--help`, so the first probe falsely read "safe". (retro-notes-from-file, PR #689, 2026-10-08)
- The release sweep's pre-flight `pnpm verify` went red on `src/cli/__tests__/cli.test.ts` "leaf command dispatches with no subcommand (doctor)" because node_modules predated a lockfile change (knip, PR #679): `doctor` exits non-zero on its `install: stale` row and the test runs `doctor`. `pnpm install --frozen-lockfile` turned it green; run it after pulling main, before the sweep's first verify. (release-sweep-v1-16-0, PR #691, 2026-10-08)
