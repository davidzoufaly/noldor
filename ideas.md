## Lessons

Raw capture point for operator/agent lessons + gotchas. `/noldor-absorb` classifies each unfiled bullet (`drop | gotcha | actionable | feedback`), files it into framework docs, and stamps `[absorbed YYYY-MM-DD → <dest>]`. Stamped bullets may be pruned — git history is the audit trail.

- `roadmap remove-block` on a promote scaffold records the entry ID in `.noldor/retired-entry-ids.json`, and `resolveIsShipped` reads a retired ID as shipped — so a `blocked-by:` dependent looks unblocked while the new FD is only in progress. `/noldor-promote` step 7 (scaffold branch) says "remove the block" without naming a command, and the CLI is the natural reach. Fix idea: promote names the command and a `--promoted` flag skips the record (the FD's `entry-id:` already carries the ID), or `remove-block` skips it when an FD with that `entry-id` exists. (found 2026-09-25 promoting Q-0320; reverted by hand) [absorbed 2026-09-29 → ideas]
- `next-priority`'s `findBlocked` treats a blocker as met the moment it leaves the queue: promoting Q-0320 to an in-progress FD made Q-0321 (`blocked-by: Q-0320`) pickable again, though `resolveIsShipped` says in-progress is not shipped. An XS/S drain can now pick Q-0321 before Q-0320 ships. Fix idea: hold back an entry whose ref resolves to an FD that is not `phase: done`. (found 2026-09-25 promoting Q-0320) [absorbed 2026-09-29 → ideas]
- `pnpm noldor design log --confirm-section 'Router (`SKILL.md`)'` fails with `sh: SKILL.md: command not found`: pnpm re-wraps arguments in double quotes for `sh`, so backticks in a heading run as command substitution, and the CLI's own "legal headings" hint prints the backticked names an agent copies. Workaround: `node bin/noldor.mjs design log …`. Fix idea: accept a heading number for `--confirm-section` as `--section` does, and say so in the hint. (found 2026-09-25) [absorbed 2026-09-29 → gotchas]
- A backgrounded `research fanout` died with exit 144 after about two minutes: three of four findings files written, no `INDEX.md`, the fourth task lost, and the children's SessionEnd hook printed "Hook cancelled". A killed batch leaves no index, so a partial batch is only found by listing `.noldor/research/<stamp>/`. Fix idea: write `INDEX.md` incrementally. (found 2026-09-25) [absorbed 2026-09-29 → gotchas]

- `pnpm noldor design archive` cannot rewrite a folded YAML `links.plan` item (`- >-` with the path on the next line) — the form the FD fmt hook itself writes for long plan paths — and on the first such item it archives that one file, prints "fix by hand" and stops: a four-part plan archived only part 1. Workaround: rewrite `links.plan` as plain one-line items and re-run. Fix idea: parse the YAML instead of matching text, and keep going past a rewrite failure.
